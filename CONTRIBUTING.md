# Contributing

This repository documents the public SQL Gym product. It does not accept application source-code contributions.

You may open a structured issue for:

- a reproducible product bug;
- unclear user documentation;
- an accessibility problem;
- an incorrect data attribution;
- a factual error in a public learning instruction.

Do not submit proprietary SQL Gym source code, copied exercise collections, credentials, personal information, or security vulnerabilities in a public issue. Use the process in [SECURITY.md](SECURITY.md) for security reports.

Submitting an issue does not grant a license to SQL Gym product materials. Proposed documentation changes may be reviewed, edited, or declined at the project owner's discretion.
