# Frequently asked questions

## Do I need to install anything?

No. The public SQL Gym runs in a modern browser. MySQL Workbench is optional and intended for learners who also want local database practice.

## Can I run SQL that differs from the expected solution?

Yes. **Run freely** accepts safe read-only SQL even when it does not solve the current task. **Check task** evaluates the returned result rather than requiring an identical query.

## Why are write commands blocked?

The training databases must remain consistent for every exercise. Commands that insert, change, or delete data are intentionally unavailable in the public training environment.

## What is the difference between a tip and a solution?

Tips reveal direction progressively. The solution displays the complete reference query. You can continue editing and experimenting after viewing either one.

## What does the information button explain?

The `i` control explains the current SQL building block, its purpose, a generic syntax pattern, and how to read that pattern.

## How does error help work?

When a query fails, expand the information section in the error message. It identifies the likely location, explains the cause, and proposes a concrete repair.

## Where is my progress stored?

Progress and drafts are stored only in the current browser. Clearing browser storage or switching devices may remove them.

## Is the Retail Lab synthetic?

No. It is an adapted, deterministic sample derived from the UCI Online Retail dataset. See [Data attribution](DATA_ATTRIBUTION.md).

## Does this repository contain the application source code?

No. This repository intentionally contains user documentation only.
