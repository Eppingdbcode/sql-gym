# Data attribution

The SQL Gym Retail Lab is adapted from the **Online Retail** dataset distributed by the UCI Machine Learning Repository.

- Creator: Daqing Chen
- Official citation: Chen, D. (2015). *Online Retail* [Dataset]. UCI Machine Learning Repository.
- Repository: [UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/352/online%2Bretail)
- DOI: [10.24432/C5BW33](https://doi.org/10.24432/C5BW33)
- Source license: [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/)

SQL Gym distributes an adapted sample for educational SQL practice. Changes include deterministic sampling by complete invoice, relational normalization, standardized timestamps, a cancellation flag, and calculated signed line totals.

The source dataset's CC BY 4.0 license applies to the underlying third-party data. SQL Gym's original interface, exercise text, evaluation behavior, documentation, branding, and other product materials remain separately protected.
